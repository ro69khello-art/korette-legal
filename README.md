# korette-legal

アプリ「これってウチだけ？」の法務文書を GitHub Pages で公開するための
リポジトリ。

**ここは公開用のコピーであって、原本ではない。** 原本はアプリのリポジトリの
`docs/legal/` にある。文面を直すときは向こうを直してから、ここへ持ってくる。

## なぜ別リポジトリなのか

App Store も Google Play も、プライバシーポリシーの**公開URL**を要求する。
アプリのリポジトリは Private で、**GitHub Pages は Private リポジトリでは
使えない**（有料プランが必要）。文書だけを分けて Public にすれば無料で済む。

アプリのソースを公開せずに済むという副次的な利点もある。不正対策の閾値
（レート制限、自動停止の通報数、表示の最小人数）がそのまま書いてあるため、
公開すると避け方の説明書を配ることになる。

## 更新のしかた

1. アプリのリポジトリで `docs/legal/privacy-policy.md` を直す
2. このリポジトリへコピーする
3. commit して push する。数分で反映される

**アプリ内の表示も同じ文面を使う。** 3か所（このページ、アプリ内、ストアの
登録欄）が食い違うと、どれが本物か分からなくなる。

## 入っているもの

- プライバシーポリシー（ストアに登録するURLはこちら）
- 利用規約

App Store は独自の利用規約か Apple の標準EULAのどちらかを求める。
UGC を持つアプリは、不快なコンテンツへの不寛容の方針を規約に含める必要が
ある（Guideline 1.2）。規約の第6条がそれにあたる。
